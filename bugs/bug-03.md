# BUG-03: Нийт номын тоолуур анх апп асаахад бодит өгөгдлөөс зөрүүтэй буруу утга харуулж байна

Орчин: Уншлагын жагсаалт v2.0, curl.exe , Windows 11, 2026-10-20
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминал дээр `curl.exe -i http://localhost:3000/api/books` хүсэлтийг явуулна.
2. Аппын веб хуудсыг шинээр асааж харахад хүснэгт дээр яг 3 ном байхад тоолуур дээр өөр утга харагдаж байгааг шалгана.

Хүлээгдэж байсан: «Нийт ном» тоолуур нь хүснэгтэд бодитоор буй номын тоотой яг тэнцүү байх ёстой.
Бодит үр дүн: Аппыг шинээр асааж ороход хүснэгт дээр 3 ном байхад тоолуур буруу буюу зөрүүтэй тоо зааж байна.

Ноцтой байдал: Minor — Хэрэглэгчид харагдах статистик мэдээлэл бодит байдалтай тохирохгүй байна.
