## Дүгнэлт
Энэхүү exploratory тестийн session-д Supermodel (GUI) аялал хамгийн олон согог (BUG-04–08) илрүүлсэн бол Saboteur аялал API/өгөгдлийн түвшний BUG-03 болон BUG-09-ийг илрүүлсэн. BUG-01 болон BUG-10 нь Couch Potato (хоосон оролт), BUG-02, BUG-04 нь Fed-Ex (өгөгдлийн зам)-ээр олдсон. Туршилт хийх явцад charter-аас гадуур серверийн гэнэтийн уналт болон порт давхардах санамсаргүй асуудлууд ажиглагдсан. Харин дараагийн session-д оролтын утгын хязгаарлалт болон хил утгуудын нарийвчилсан шалгалтуудыг бүрэн хамруулж шалгахаар үлдээв. Эдгээр илэрсэн согогуудаас номын тоолуурын зөрүү болон хуучин хувилбарын сервер талын алдаанууд нь Лаб 1-ийн Playwright автомат тестээр шууд баригдах боломжтой байсан. Харин устгах товчны өнгөний алдаа, мессежийн оновчгүй байдал болон UI дээрх форматын гажигнууд нь зөвхөн хүний нүдээр харахад л олдох боломжтой байв. Урт гарчгаас хүснэгт эвдрэх зэрэг харагдах байдлын согогийг Playwright тест барихгүй анхнаасаа алдаатай байсан төлөвийг baseline болгон авах тул зөвхөн хүний нүдээр олдох байсан. Иймээс автомат тест нь урьдчилан тодорхойлсон хүлээгдэх үр дүнг шалгаж регрессээс хамгаалдаг бол exploratory тест нь урьдчилан таамаглаагүй согогийг илрүүлэхэд илүү үр дүнтэй гэж дүгнэв.
