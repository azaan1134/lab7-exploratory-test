## Дүгнэлт
Энэхүү exploratory тестийн session-д Supermodel аялал хамгийн олон согог илрүүлсэн бол Saboteur аялал API болон өгөгдлийн түвшний алдаануудыг олсон. BUG-01 болон BUG-10 согогууд Couch Potato аялалаар, Charter-аас гадуур BUG-02 ба BUG-04 нь Fed-Ex аялалаар тус тус олдсон болно. Туршилт хийх явцад сервер дахин асаагаагүйгээс хуучин өгөгдөлтэй тестлэсэн явдал тест үр дүнг буруу гарахад нөлөөтэйг ажиглав. Дараагийн session-д оролтын утгын хязгаарлалт болон хил утгуудын нарийвчилсан шалгалтуудыг бүрэн хамруулж шалгахаар үлдээв. Илэрсэн согогуудаас номын тоолуурын зөрүү болон хуучин хувилбарын сервер талын алдаанууд нь Лаб 1-ийн Playwright автомат тестээр шууд баригдах байсан юм. Мөн “1,971” гэх мэт оны форматын согог (Тийм assertion бичсэн тохиолдолд л баригдана) болон Устгах товчны ногоон өнгө зэрэг харагдах байдлын гажиг зөвхөн хүний нүдээр олдох боломжтой байв. Иймээс автомат тест нь урьдчилан тодорхойлсон хүлээгдэх үр дүнг шалгаж регрессээс хамгаалдаг болох нь харагдлаа. Харин exploratory тест нь урьдчилан таамаглаагүй согогийг шууд газар дээр нь илрүүлэхэд илүү үр дүнтэй байлаа.
