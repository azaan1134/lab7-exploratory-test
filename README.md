## Дүгнэлт
Энэхүү exploratory тестийн session-ий явцад **Saboteur** аялал хамгийн үр дүнтэй байж, аппын өгөгдлийн болон API түвшний нууц согогуудыг илрүүлэхэд чухал үүрэг гүйцэтгэв. Тухайлбал, BUG-01 болон BUG-10 согогууд *Couch Potato* аялалаар (хоосон оролт өгөх үед), харин BUG-03 болон BUG-09 согогууд *Saboteur* болон *Fed-Ex* аялалуудын үеэр илэрсэн юм. Туршилт хийх явцад charter-аас гадуур серверийн гэнэтийн уналт болон порт давхардах санамсаргүй асуудлууд ажиглагдсан. Харин дараагийн session-д оролтын утгын хязгаарлалт болон хил утгуудын нарийвчилсан шалгалтуудыг бүрэн хамруулж шалгахаар үлдээв. Эдгээр илэрсэн согогуудаас номын тоолуурын зөрүү болон хуучин хувилбарын сервер талын алдаанууд нь Лаб 1-ийн Playwright автомат тестээр шууд баригдах боломжтой байсан. Харин устгах товчны өнгөний алдаа, мессежийн оновчгүй байдал болон UI дээрх форматын гажигнууд нь зөвхөн хүний нүдээр харахад л олдох боломжтой байв. Урт гарчгаас хүснэгт эвдрэх зэрэг харагдах байдлын согогийг Playwright тест барихгүй анхнаасаа алдаатай байсан төлөвийг baseline болгон авах тул зөвхөн хүний нүдээр олдох байсан. Иймээс автомат тест нь урьдчилан тодорхойлсон хүлээгдэх үр дүнг шалгаж регрессээс хамгаалдаг бол exploratory тест нь урьдчилан таамаглаагүй согогийг илрүүлэхэд илүү үр дүнтэй гэж дүгнэв.
